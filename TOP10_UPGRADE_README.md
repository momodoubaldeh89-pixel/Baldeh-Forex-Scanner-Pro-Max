# Top-10 email upgrade

This package keeps the mobile-friendly Streamlit scanner and hourly GitHub Actions email scanner. The email workflow ranks qualifying Forex, US stocks, and commodities by a rule-based quality score and sends at most the newly qualifying/changed members of the current top 10, rather than emailing every qualifying signal.

Read `EMAIL_ALERTS_SETUP.md` before uploading. Preserve the workflow at `.github/workflows/hourly-email-alerts.yml`. Keep your GitHub Actions secrets private.
